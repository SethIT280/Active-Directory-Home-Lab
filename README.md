# Active Directory Home Lab

## Overview
This is my Active Directory home lab, built to gain hands-on administration experience. I'm using it to practice managing user accounts, organizing them with OUs, and handling the DNS and DHCP services they depend on. This is just the beginning, and I will keep updating the documentation as I learn more.

## Environment
- **Hypervisor:** VirtualBox
- **Server OS:** Windows Server 2025 Datacenter Evaluation (Desktop Experience)
- **VM specs:** 2 cores, 4 GB RAM, 50 GB disk
- **Domain name:** AGNB.lab
- **Server IP:** 10.0.2.10/24 (static)
- **Network:** VirtualBox NAT Network (10.0.2.0/24)
- **Roles:** Active Directory Domain Services, DNS, DHCP
- **Client VM:** Windows 11
